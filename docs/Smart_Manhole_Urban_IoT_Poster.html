Objectives & Urban Challenge

The Sub-surface Crisis: Traditional urban manholes are "black boxes." Siltation causes sudden street flash floods; toxic sewer gas accumulation (Methane, H₂S) asphyxiates sanitation workers; and displaced or stolen lids cause severe vehicular road accidents.

Project Objectives
  • Continuous Edge Sensing: 24/7 autonomous monitoring of flood depth, gas levels, temperature, and lid displacement.
  • Dual-Mode Real-Time Link: Sub-20ms direct local SCADA WebSocket + 15s historical cloud telemetry.
  • Interactive 3D Digital Twin: Physics-accurate visual twin rendering lid kinematics and fluid surcharge.
  • Zero Fatalities / Proactive Alarms: Instant local buzzer + automated city command center alerts.
★
Real-Time Urban Applications
  • Municipal Flood Defense: Real-time stormwater depth sensing alerts city drainage teams before street inundation.
  • Sanitation Worker Safety: Pre-entry gas screening directly prevents lethal toxic gas poisoning.
  • Anti-Theft Cable Protection: Instant tamper alarms guard underground optical fiber and high-voltage power conduits.
  • Roadway Traffic Safety: Displaced lid alerts notify police and road authorities in seconds.

Dual-Core Hardware Architecture

The system employs a dual-processor distributed architecture separating deterministic real-time sensing from wireless networking:

  • STM32F103C8T6 (ARM Cortex-M3 @ 72MHz): Bare-metal CMSIS firmware cycling an ultra-fast 10Hz non-blocking multi-sensor engine.
  • NodeMCU V3 (ESP8266 Gateway): Receives STM32 JSON over USART1 (115200 baud). Hosts local REST server & pushes to ThingSpeak.

Engineering Bottlenecks Solved
  • GCC nano.specs Float Bug: ARM GCC nano.specs stripped %f in snprintf, leaving LCD blanks (D:cm, T:C).
    SOLVED Re-engineered with fixed-point integer formatting (%d.%d).
  • Bit-Bang I2C Repeated-Start Hang: MPU6050 ACK held SDA low during repeated starts, forcing tilt to 0°.
    SOLVED Replaced with clean Stop-Start cycle with 10µs bus settling.
  • DS18B20 750ms Blocking Freeze: 12-bit temp conversion stalled MCU execution for almost a second every loop.
    SOLVED Created an asynchronous non-blocking state machine at 10Hz.
  • Browser / CDN 300s Stale Cache: Browsers cached ThingSpeak feeds/last.json for 5 minutes.
    SOLVED Added dynamic timestamp cache-busters (?_=${Date.now()}) & no-store.
  • Echo 5V-to-3.3V Logic Protection: HC-SR04 Echo 5V would destroy non-5V-tolerant ADC pin PA2.
    SOLVED Integrated precision 1kΩ / 2kΩ voltage divider (3.33V safe).

3D Digital Twin & Future Work

Interactive SCADA 3D Twin: Powered by React 18 + Three.js + Vite deployed globally on GitHub Pages:

  • Kinematic Lid Motion: Real-time hinge rotation mirrors MPU-6050 accelerometer pitch/roll.
  • Volumetric Fluid Surcharge: Shader-rendered water level calculates chamber capacity % from HC-SR04.
  • Automated Alarms: Visual alert banners + audio sirens dispatch when thresholds breach.
