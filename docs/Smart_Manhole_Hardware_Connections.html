1. Master System Hardware Architecture

The system utilizes a Dual-Core Distributed Architecture: an ultra-reliable STM32F103C8T6 (ARM Cortex-M3 @ 72MHz) acts as the bare-metal deterministic sensor controller sampling at 10Hz, linked over full-duplex UART to an ESP8266 NodeMCU V3 Wi-Fi gateway that transmits telemetry simultaneously to ThingSpeak Cloud and local real-time WebSockets.

3. Critical HC-SR04 Echo Level Shifter Circuit

The HC-SR04 Echo pin outputs 5V TTL logic. STM32 pin PA2 is an ADC input pin and is NOT 5V tolerant (maximum voltage 3.6V). Connecting Echo directly to PA2 will damage the STM32 microcontroller. The 1kΩ / 2kΩ resistive voltage divider safely steps down the 5.0V echo pulse to 3.33V:

Formula: \( V_{\text{out}} = V_{\text{in}} \times \frac{R_2}{R_1 + R_2} = 5.0\text{V} \times \frac{2000}{1000 + 2000} = 3.333\text{V} \)

5. Step-by-Step Hardware Checkout & Debugging Protocol
  1. Common Ground Verification: Ensure STM32 GND, NodeMCU GND, and all sensor grounds meet at a unified ground bus. Without common GND, UART packets and I2C will drop bits.
  2. I2C Bus Address Scan: On boot, the LCD splash screen displays MPU OK (0x68). If it shows NO MPU SENSOR!, check if the GY-521 AD0 pin is connected to GND and verify 3.3V power.
  3. Serial Gateway Monitoring: Open Arduino IDE Serial Monitor at 115200 baud on the NodeMCU port. It will display: 
    [STM32 Data] Dist: 25.0cm | Gas: 790 | Temp: 28.0C | Tilt: 0.0 deg | Cover: COVER CLOSED
[ThingSpeak] Success! Entry ID #482 recorded.
  4. Zero-Latency Local Mode: In your web dashboard at https://pvkkr.github.io/smart-manhole-twin/, enter http://<NodeMCU_IP>/telemetry under Settings $\rightarrow$ Hardware URL to stream telemetry with under 20ms latency!
